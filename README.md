# 🛰️ Space Debris

An interactive web project exploring the challenges of space debris and the future of space sustainability.

🌐 **[View Live Project](https://pcodeswritings.github.io/space-debris/)**

## About

This project was developed as part of my Swiss Matura research project on space debris.

It explores the growing issue of orbital debris across different Earth orbits, combining research, interactive web development and visualization to make the topic more accessible.

## Topics explored

- Space debris across different orbital regions
- Sources and evolution of orbital debris
- The Kessler Syndrome
- Risks to satellites, spacecraft and the ISS
- Detection and tracking methods
- Debris mitigation and removal technologies
- Space sustainability

## Built with

- HTML
- CSS
- JavaScript
- Spline
- GitHub Pages

## Project

The goal was to transform a complex scientific and technological topic into an accessible and engaging digital experience.
